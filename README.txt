                             AllBinary Platform Umka

What is it?

This repository contains code generated by the AllBinary Platform for support in Umka.  
This repo is used to allow developers to skip the Umka code generation step.

What are some example games with this Umka code?

https://allbinary.itch.io (The downloads with "-umka" in the filename are Umka only builds. Currently that only includes nothing. Also the Umka builds are not available on Google Play or other stores.)
